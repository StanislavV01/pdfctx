# pdfctx v0.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a PDF retrieval engine that measurably beats a page baseline and pdf-mcp on FinanceBench, then expose it to agents over MCP, REST and CLI with an audit log.

**Architecture:** Parse PDFs into structured blocks and a section tree. Derive retrieval units (blocks, whole tables, table rows) with context prefixes, store them in SQLite with FTS5 plus optional vectors, and search through a configurable BM25 → vectors → RRF → rerank pipeline. The benchmark drives every retrieval change. A `Library` façade with an audit log sits under the MCP server, the FastAPI app and the CLI.

**Tech Stack:** Python ≥ 3.11, pdfplumber, pypdf, sqlite3/FTS5, mcp 2.3 (`MCPServer`), FastAPI, uvicorn; optional fastembed; pytest, reportlab, ruff, httpx.

**Spec:** `docs/superpowers/specs/2026-11-27-pdfctx-design.md`

## Global Constraints

- Package `pdfctx`, `src/` layout, hatchling, console script `pdfctx = pdfctx.cli:main`, `__version__ = "0.1.0"`.
- Runtime deps: `pdfplumber>=0.11`, `pypdf>=5`, `mcp>=2.3,<3`, `fastapi>=0.115`, `uvicorn>=0.30`. Extra `embed = ["fastembed>=0.4"]`. Dev extra: `pytest`, `reportlab`, `ruff`, `httpx`.
- IDs: document = first 12 hex of sha256(resolved absolute path); section `{doc}:s{n}`; block `{doc}:b{n}`; unit `{doc}:u{n}`.
- `bbox` = `(x0, top, x1, bottom)` in points, top-left origin, rounded to 1 decimal. Pages are 1-based.
- `tokens(text) = ceil(len(text) / 4)`.
- Document `status` ∈ `ok | no_text | encrypted | failed`. A bad file never stops indexing of the others.
- FTS5 tokenizer `unicode61 remove_diacritics 2`; queries pass through `fts_query()` only.
- Errors raised to users are `PdfctxError(message)`; interfaces print the message, never a traceback.
- FinanceBench data is downloaded at run time into `~/.cache/pdfctx-bench` (override `PDFCTX_BENCH_DIR`); nothing from it is committed.
- FastAPI is missing from the build sandbox: API tests use `pytest.importorskip("fastapi")` and run in CI.
- Commits: Conventional Commits, author `Stanislav <83041246+StanislavV01@users.noreply.github.com>`, no trailers.

## Review Focus

1. FTS5 metacharacters in queries (`"`, `-`, `AND`, `NEAR(`, `*`, `:`, `((`, empty, punctuation-only) never raise. Owner: Task 4 `test_fts_query_is_injection_safe`.
2. Encrypted, corrupt, empty and image-only PDFs in a folder. Owner: Task 4 `test_index_folder_with_bad_files`.
3. A file changed or deleted after indexing is re-indexed or dropped, and stale ids answer "unknown block". Owner: Task 4 `test_reindex_on_change_and_delete`.
4. Diacritics and Cyrillic: `zazolc` finds `zażółć`, and Cyrillic words match. Owner: Task 4 `test_search_diacritics_and_cyrillic`.
5. The FinanceBench 0-based → 1-based page conversion. If it is wrong, every number is silently wrong. Owner: Task 5 `test_evidence_page_conversion`.

### Task 2: Parsing (lines, blocks, tables, status)

**Files:** `src/pdfctx/parse/{__init__,model,lines,blocks,pdf}.py`; `tests/test_parse.py`.

**Interfaces:**
- `model.py`: `Line(page, text, bbox, size, bold)`, `RawBlock(kind: "heading"|"paragraph"|"table", page, bbox, text, size, bold, rows: list[list[str]] | None = None, lead_in: str = "")`, `ParsedDoc(path, title, pages, blocks, bookmarks: list[tuple[int, str, int]], status, error)`.
- `lines.extract_lines(page, page_no, exclude) -> list[Line]`; `lines.drop_running_lines(by_page, heights) -> by_page` (top/bottom 8%, digits→`#`, ≥ 50% of pages, min 3 pages).
- `blocks.body_size(lines) -> float`; `blocks.is_heading(line, body) -> bool` (size ≥ 1.15× body, or bold and ≤ 12 words standalone, or numbering pattern `^\d+(\.\d+)*\s|^(Item|Article|Part|Section)\s+\w+|^§`); `blocks.group_blocks(lines, body, page_width) -> list[RawBlock]` (columns split at x-gaps ≥ 15% page width; paragraph break at vertical gap > 1.5× median gap; de-hyphenation).
- `pdf.parse_pdf(path: Path) -> ParsedDoc`. Tables come from `find_tables()` and are kept at ≥ 2×2; cells `None`→`""`; `text` = markdown; `lead_in` = the last line of text above the table on the same page, within 30 pt. Title comes from metadata, else the first heading, else the file stem. Encrypted → `encrypted`. Exception → `failed` with the first line of the error (≤ 200 chars). Fewer than 20 chars of text → `no_text`.

- [ ] Tests: `test_report_blocks` (heading order; table rows, `lead_in == "Revenue by region (in thousands):"`; header/footer gone), `test_two_column_reading_order`, `test_bad_files_status`, `test_real_pdfs_parse` (federal-register ≥ 5 headings; nics table ≥ 10 rows) → commit `feat(parse): structured blocks, tables and document status`.

### Task 3: Outline and retrieval units

**Files:** `src/pdfctx/outline.py`, `src/pdfctx/units.py`; `tests/test_outline_units.py`.

**Interfaces:**
- `outline.Section(idx, parent, level, title, page)`; `build_outline(doc) -> tuple[list[Section], list[int | None]]`. With bookmarks, sections come from bookmarks and blocks attach by page and a heading-title match. Without bookmarks, sections come from headings; level = numbering depth, else rank of heading size.
- `units.Unit(kind: "block"|"table"|"row", block_idx: int, text: str, context: str, page: int, bbox)`. `make_units(doc, sections, assign, contextual: bool, table_rows: bool) -> list[Unit]` produces:
  - a `block` unit for each paragraph or heading;
  - a `table` unit for each table, with `text = lead_in + header + all rows`;
  - when `table_rows` is set, a `row` unit for each data row, `"{row[0]} | {h1}: {c1} | {h2}: {c2} …"` with the bbox of the table.
  
  `context` = `"{title} › {section path}"` when `contextual`, else `""`.

- [ ] Tests: `test_outline_from_bookmarks`, `test_outline_from_headings`, `test_row_units_carry_headers` (`"North | 2025: 1,200 | 2024: 1,050"`), `test_context_prefix` → commit `feat: section tree and table-aware retrieval units`.

### Task 4: Store, indexer, search

**Files:** `src/pdfctx/{store,indexer,embed,search}.py`; `tests/test_index_search.py`.

**Interfaces:**
- `store.Store(path)`, with tables `documents`, `sections`, `blocks` (rows JSON for tables), `units`, `units_fts` (FTS5 over `context`, `text`, with the context column weighted 0.5), `vectors(unit_id, data BLOB)` and `audit`, in WAL mode. Methods: `upsert_document`, `replace_contents(doc_id, sections, blocks, units, vectors=None)` (one transaction), `delete_document`, `list_documents`, `get_document`, `get_section`, `section_children`, `blocks_in_section(section_id, recursive)`, `get_block`, `get_unit`, `units_for(doc_ids)`, `append_audit`, `audit(limit)`. Unknown ids raise `PdfctxError("unknown block '…'")` and the like.
- `indexer.IndexOptions(contextual=True, table_rows=True, embedder=None)`; `index_paths(store, paths, options) -> IndexReport(added, updated, unchanged, removed, problems)`. It skips files whose sha256 has not changed, and drops documents whose file is gone or whose options changed (the options hash is stored per document).
- `embed.Embedder` protocol (`dim`, `embed(texts) -> list[list[float]]`), `HashEmbedder(dim=256)`, `FastEmbedder(model)`; `embed.Reranker` protocol (`score(query, texts) -> list[float]`), `FastReranker(model)`; `get_embedder(name)` and `get_reranker(name)` for `None | "hash" | "fastembed"`. A missing extra raises `PdfctxError` with the install hint.
- `search.fts_query(text) -> str | None`. `search.SearchConfig(bm25=True, vectors=False, rerank=False, k_candidates=50, rerank_top=30)`. `search.search(store, query, doc_ids=None, k=8, config=SearchConfig(), embedder=None, reranker=None) -> list[Hit(unit_id, block_id, score)]`: RRF with constant 60; the reranker reorders the top `rerank_top`; results are deduplicated by block, keeping the best unit, so a table and its rows count once.

- [ ] Tests: `test_index_and_read_back`, `test_index_folder_with_bad_files`, `test_reindex_on_change_and_delete`, `test_unchanged_files_are_skipped`, `test_fts_query_is_injection_safe`, `test_search_diacritics_and_cyrillic`, `test_row_unit_wins_for_line_item_query` ("South revenue 2024" → the table block first), `test_hybrid_with_hash_embedder` → commit `feat: SQLite index with FTS5, optional vectors and rerank`.

### Task 5: FinanceBench benchmark

**Files:** `bench/__init__.py`, `bench/financebench.py`, `bench/systems.py`, `bench/README.md`, `tests/test_bench.py`, `.github/workflows/bench.yml` (`workflow_dispatch`: install `.[embed]` and `pdf-mcp`, run all systems, upload `bench/results` as an artifact).

**Interfaces:**
- `financebench.load(bench_dir) -> list[Question(id, doc_name, question, answer, evidence_pages: set[int], evidence_texts: list[str])]` with pages converted to 1-based; `ensure_data(bench_dir, docs: list[str])` downloads with a sparse `git` checkout of the pinned FinanceBench commit.
- `systems.System` protocol: `name`, `prepare(pdf_paths) -> None`, `retrieve(question, doc_name | None, k) -> list[Passage(doc_name, page, text)]`. Implementations: `BaselinePage` (pypdf page text + FTS5), `Pdfctx(options, config, embedder, reranker, name)`, `PdfMcp` (imports `pdf_mcp` and calls its corpus/document search through its Python API; `prepare` raises a clear skip when it is not installed).
- `financebench.score(questions, results) -> dict` with `page_recall@{1,3,5,10}`, `mrr@10`, `tokens@5` and `latency_p50_ms`. `run(systems, scope: "doc"|"corpus", limit=None) -> writes bench/results/{scope}-{name}.json` and prints a markdown table. CLI: `python -m bench.financebench --systems baseline,pdfctx-bm25,... --scope doc [--limit N]`.
- Ablation names: `pdfctx-structure` (units without context or rows), `pdfctx-context`, `pdfctx-tables` (context + rows), `pdfctx-hybrid` (+ fastembed), `pdfctx-rerank` (+ reranker).

- [ ] Tests: `test_evidence_page_conversion` (for 5 questions, normalized evidence text overlaps the pypdf text of the converted page by ≥ 50% of tokens; skipped when the data is absent), `test_score_math` (synthetic results → exact recall/MRR), `test_baseline_on_generated_pdf` → commit `feat(bench): FinanceBench harness with baseline and ablations`.

### Task 7: Context tools and Library with audit

**Files:** `src/pdfctx/{context,library}.py`; `tests/test_library.py`.

**Interfaces:**
- `context.render_section(store, section_id, max_tokens)`, `context.cite(store, block_id)`, `context.context_pack(store, hits, budget_tokens)`. For a `row` hit, the pack contains the table header row plus that row, not the whole table. Blocks are deduplicated, sorted by document order and grouped under their section path, with `used_tokens <= budget`.
- `library.Library(db_path, roots=None, options=IndexOptions(), config=SearchConfig(), embedder=None, reranker=None, client="local")` exposes the seven tools and `audit(limit)`. Each tool call appends one audit row with ts, client, tool, args, returned block ids and doc ids. Changed roots are refreshed lazily, at most once every 2 s. Validation: `k` 1–50, `max_tokens` 100–20000, `budget_tokens` 200–50000, `format` ∈ {markdown, csv}.

- [ ] Tests: `test_tools_end_to_end`, `test_context_pack_uses_row_not_whole_table`, `test_every_tool_call_is_audited`, `test_argument_validation`, `test_get_table_csv` → commit `feat: context tools and Library with audit log`.
